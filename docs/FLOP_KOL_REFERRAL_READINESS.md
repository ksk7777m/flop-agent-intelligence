# FLOP KOL Referral Attribution and Program Readiness

This package records a reviewed 2026-09-10 announcement state: a KOL
leaderboard, unique referral links, referral-related network-use tracking, and
wallet-from-referral lottery eligibility were announced, while program details,
issuance endpoints, domains, rules, formulas, windows, rewards, self-referral,
Sybil policy, and public leaderboard remain unresolved or unpublished. This is
a pinned reviewed state, not a live fetch or continuing-currentness claim.

The offline validator accepts only canonical commitment artifacts. Exact source,
program, rules, referral link, domain, referrer, issue context, and version
bindings must match a reviewed public authority manifest. Production has an
empty manifest and therefore fails closed. Raw URLs, codes, usernames, wallet
addresses, user identities, query data, signatures, and source paths are
rejected rather than projected.

A verified referral remains distinct from attribution. Attribution evidence
requires separately committed wallet creation, network use, timestamp/source,
and the exact program rules, but can reach only evidence readiness. It never
proves an attributed user, tracked use, rank, reward, lottery eligibility,
agent-airdrop eligibility, or authorization. HTTP, X, Technocore, MCP, browser,
analytics, wallet, signer, referral click, registration, and claim clients are
absent.
